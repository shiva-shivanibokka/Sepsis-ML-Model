# Serving requirements for the container image.
#
# This file used to be an exact lock, because the served artifact was a pickle
# and a pickle only loads under the versions that wrote it — numpy 2.x cannot
# unpickle arrays written by 1.26, scikit-learn pickles break across minor
# releases, and the pinned XGBoost build was not even on PyPI, so the lock could
# not actually be installed from a clean environment.
#
# The service now loads artifacts/model.ubj through XGBoost's own loader, which
# is documented as stable across library versions, and applies the scaler from
# artifacts/serving.json as plain arithmetic. Nothing is unpickled, so ranges are
# safe and scikit-learn, pandas, scipy-via-sklearn, joblib and imbalanced-learn
# are no longer part of the runtime at all.
#
# Regenerate artifacts/model.ubj + serving.json with `python export_serving.py`,
# which refuses to write them unless they reproduce the trained pipeline exactly.
numpy>=1.24,<3
xgboost>=2.0
fastapi>=0.110
uvicorn[standard]>=0.29
pydantic>=2.6
